# Практична робота з інформатики (5 клас)
## Тема: «Алгоритми і програми»

Інтерактивний навчальний вебпрактикум для учнів 5 класу з багатосторінковою навігацією, двома інтерактивними симуляторами (кроковий виконавець алгоритму та складання програми з команд), двома практичними частинами, підсумковим тестом та автоматичним формуванням звіту для друку (A4).

### Запуск локально або на GitHub Pages
1. Розпакуйте архів у папку та відкрийте `index.html` у браузері (усі стилі та скрипти вбудовані в `index.html`, а також продубльовані у `css/` та `js/`).
2. Для публікації на GitHub Pages завантажте вміст папки у репозиторій та увімкніть **Settings → Pages → Deploy from a branch → main / (root)**.
